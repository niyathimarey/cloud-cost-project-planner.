# Cloud Cost Comparison

## Purpose
This document explains how cloud-service estimates can be compared during early project planning.

|---|---:|

**Note:** These are fictional sample values used to demonstrate the application. They are not official cloud prices.

## Planning Scenarios

### Scenario A: Small Prototype
Suitable for testing an idea with limited expected usage. The team should identify essential services and avoid paying for resources it does not need.

### Scenario B: Growing Application
A project with more users may need additional compute, storage, database capacity, monitoring, and security controls.

### Scenario C: Production Application
A production system may require stronger availability, backup, security, monitoring, and disaster-recovery measures. These requirements can increase costs.

## Cost Planning Checklist
- Define expected user traffic.
- Estimate storage and data transfer.
- Identify compute and database needs.
- Include monitoring, backups, and security.
- Review the estimate against the approved budget.
- Revisit estimates when project requirements change.
